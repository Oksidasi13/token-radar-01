A token launch radar that ranks 198 tokenless protocols by implied value. The radar-2 model scores each protocol as TVL times a log-tiered size multiple, a clamped growth multiplier, and a maturity multiplier, and filters out wrapped, staked, bridged, liquid-staking, restaking and restaked-BTC products whose tokens already trade. The board covers the full 40-protocol watchlist plus 158 early pre-token protocols, gives every row a six-step farm plan, and ships with a static dashboard (sortable board, per-protocol detail, live model sliders).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input <path-to-snapshot.json>
```
